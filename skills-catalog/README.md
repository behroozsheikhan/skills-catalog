# 🔎 کتابخانهٔ Agent Skills — جستجوی تمام‌متنی

**۷٬۷۶۴ اسکیل** از **۲۰۷ منبع**، با توضیح کامل — پوشش **۱۰۰٪** کاتالوگ <https://mcpservers.org/agent-skills>

## استفاده

```bash
cd ~/skills-catalog

python3 search.py "saas pricing"              # جستجوی طبیعی
python3 search.py "cold email" --official     # فقط منابع رسمی (★)
python3 search.py "pdf" --topic document      # محدود به موضوع
python3 search.py "react" --author vercel     # محدود به منبع
python3 search.py "kubernetes" -n 5           # فقط ۵ نتیجه
python3 search.py "terraform" --show          # با متن هایلایت‌شده

python3 search.py --stats      # آمار ایندکس
python3 search.py --topics     # نقشهٔ موضوعی
python3 search.py --sources    # ۲۰۷ منبع

python3 update_index.py       # به‌روزرسانی افزایشی (اسکیل‌های جدید)
python3 build_db.py           # ساخت دوبارهٔ skills.db
```

## چطور جستجو می‌کند

- **FTS5** با توکن‌ساز `porter unicode61` → ریشه‌یابی انگلیسی (`deploy`/`deploying`/`deployment` یکی می‌شوند) و حذف اَکسنت
- همهٔ کلمات عبارت جستجو باید پیدا شوند (AND)
- رتبه‌بندی با `bm25` — توضیحات و نام‌ها وزن بیشتری دارند
- ستون `★` = منبع رسمی و قابل‌اعتماد

## نکته‌ها

- طبقه‌بندی موضوعی **خودکار و بر پایهٔ نام اسکیل** است — توضیحات در آن دخالت ندارند، پس «سایر / عمومی» بزرگ‌ترین گروه است. برای جستجوی دقیق‌تر از متن توضیحات استفاده کن (`search.py`).
- **۴٬۱۷۲ اسکیل** از منابع رسمی (Anthropic، OpenAI، GitHub، Microsoft، NVIDIA، Vercel، Google، Cloudflare، Figma، Notion، Stripe، Sentry، Hugging Face، Prisma، Firecrawl، PostHog) — این‌ها قابل‌اعتمادترند.
- **لینک گیتهاب: ۷٬۷۶۴ از ۷٬۷۶۴ اسکیل (۱۰۰٪)** — استخراج از صفحهٔ هر اسکیل + تأیید دستی کاربر برای ۲۳ مورد؛ تک‌تک با HEAD تست شده‌اند.
- ۷ اسکیل مرده/بی‌منبع حذف شده‌اند (`removed.jsonl`) و دیگر در به‌روزرسانی‌ها برنمی‌گردند.
- متن کامل فقط برای ۳۴۸ اسکیل دانلود شده (سایت محدودیت نرخ Cloudflare دارد). اگر لازم شد `fetch_skills.py` با `RPS=1.2` اجرا کنید.
